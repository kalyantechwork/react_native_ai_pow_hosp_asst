Part 02 · Project creation

Create a fresh Expo SDK 58 project

Open VS Code, open Terminal → New Terminal, and run this command. It creates a new project folder and installs the Expo framework's starter dependencies as part of project creation.

Create the blank SDK 58 app
npx create-expo-app@latest hospital_ai_assistant --template blank@58

Creates a fresh blank React Native Expo app using SDK 58. Choose the blank template because this project uses React Navigation; the default template includes Expo Router, which is not used in this app.

  • npx runs a package command without requiring a global installation.
  • create-expo-app@latest runs the current Expo project generator.
  • hospital_ai_assistant is the folder name for the new project.
  • --template blank@58 chooses the blank starter template for SDK 58.
  • The generator already installs the core Expo, React, and React Native packages. Do not add manual version numbers for those core packages.
Enter the new project folder
cd hospital_ai_assistant

Moves the terminal into the project directory. All following package installation commands must run from this folder.

Why not the default template? The default template is designed around Expo Router. This project uses React Navigation's bottom tabs and native stack, so the blank template provides a clean starting point without an extra routing system.

Install each dependency and understand its purpose

Run the following commands one by one from inside hospital_ai_assistant. You will use two types of package installation commands:

npm install package-nameInstalls general JavaScript libraries such as React Navigation.

1. Check Node.js
node -v

Shows the installed Node.js version. Expo SDK 58 requires a supported modern Node.js release; this project records Node.js 22.13.0 or newer as its minimum.

  • If the command is not recognized, install Node.js LTS and reopen the terminal.
2. Check npm
npm -v

Shows the npm version. npm is installed along with Node.js and is used for JavaScript package installation.

  • You do not need to install npm separately when Node.js is installed.
3. Create the SDK 58 blank Expo app
npx create-expo-app@latest hospital_ai_assistant --template blank@58

Creates the project folder and installs the Expo framework's starter dependencies automatically. The blank template is selected because this project uses React Navigation rather than Expo Router.

  • npx runs the create-expo-app command without a separate global CLI installation.
  • create-expo-app generates the initial Expo project.
  • @latest selects the current create-expo-app CLI.
  • hospital_ai_assistant is the new project folder name.
  • --template blank@58 selects the blank template for Expo SDK 58.
  • The scaffold already installs the matching Expo, React, and React Native core packages.
4. Move into the project folder
cd hospital_ai_assistant

Changes the terminal's current directory to the newly created app. Run all following package commands from inside this folder.

  • cd means change directory.
  • The terminal path should now end with hospital_ai_assistant.
5. Install React Navigation core
npm install @react-navigation/native

Installs the core React Navigation library. It provides the navigation container and shared navigation APIs used by the app.

6. Install native stack navigation
npm install @react-navigation/native-stack

Installs the native stack navigator. It provides screen-to-screen navigation such as Home → Doctor Details → Appointment, including back navigation.

7. Install bottom tab navigation
npm install @react-navigation/bottom-tabs

Installs the bottom tab navigator used for the Home and AI Assistant tabs.

8. Install Expo-compatible native navigation dependencies
npx expo install react-native-screens react-native-safe-area-context

Installs the native screen and safe-area packages at versions compatible with the Expo SDK in this project.

  • react-native-screens helps React Navigation use native screen containers.
  • react-native-safe-area-context provides safe-area insets around notches, status bars, and device edges.
  • Use npx expo install for native packages so Expo selects SDK-compatible versions.
9. Install Expo vector icons
npx expo install @expo/vector-icons

Installs the icon library used for the hospital, doctor cards, tab bar, buttons, and chat UI. The project imports Ionicons from this package.

10. Install Expo font support
npx expo install expo-font

Provides font loading support used by Expo icon fonts and other font assets.

11. Install the Expo status bar package
npx expo install expo-status-bar

Provides the StatusBar component used in App.js to control the appearance of the device status bar.

12. Install Expo system UI support
npx expo install expo-system-ui

Provides Expo's system UI integration for app-level system appearance and background handling.

13. Check dependency and project health
npx expo-doctor@latest

Runs Expo Doctor to check the project configuration and dependency compatibility. Review warnings before moving on.

14. Start the Metro development server
npx expo start

Starts Expo's development server (Metro) and displays a QR code plus keyboard shortcuts in the terminal.

  • Press a to open an Android emulator when one is running.
  • Press i for an iOS simulator on macOS with Xcode.
  • Press w to open the web version when the project's dependencies support it.
15. Restart with a clean Metro cache
npx expo start --clear

Clears Metro's cached transform data before starting the development server. Use this after changing environment variables or when stale bundle/cache issues occur.

Important: The Expo project generator already installed Expo, React, and React Native. Do not install those core packages separately. The commands above add only the navigation and Expo modules used by the app's source code.

Part 05 · Architecture

Understand the app before writing the screens

The app has two bottom tabs. The Home tab contains a nested stack so users can open a doctor profile and appointment form without losing the tab navigation.

NavigationContainer
└── Bottom Tab Navigator
    ├── Home tab
    │   └── Native Stack Navigator
    │       ├── HomeScreen
    │       ├── DoctorDetailsScreen
    │       └── AppointmentScreen
    └── AI Assistant tab
        └── AIChatScreen
ScreenPurposeNavigation action
HomeHospital landing page and doctor listOpens Doctor Details or AI Assistant
Doctor DetailsDisplays the selected doctor's profileOpens Appointment
AppointmentLocal appointment form demonstrationShows demo confirmation
AI AssistantHospital FAQ chat with optional Gemini responsesRemains in the Assistant tab
Data flow: The Home screen reads doctors.js and passes a doctor's id to the details screen. The AI screen calls gemini.js, which uses the offline FAQ data or makes a Gemini API request.

  }

  if (value.includes("fee") || value.includes("cost") || value.includes("price") || value.includes("charge")) {

import React from "react";
import { createBottomTabNavigator } from "@react-navigation/bottom-tabs";
import { createNativeStackNavigator } from "@react-navigation/native-stack";
import { Ionicons } from "@expo/vector-icons";
import HomeScreen from "../screens/HomeScreen";
import DoctorDetailsScreen from "../screens/DoctorDetailsScreen";
import AppointmentScreen from "../screens/AppointmentScreen";
import AIChatScreen from "../screens/AIChatScreen";
import { colors } from "../theme";

const Tab = createBottomTabNavigator();
const Stack = createNativeStackNavigator();

function HomeStackNavigator() {
  return (
    <Stack.Navigator
      screenOptions={{
        headerShown: false,
        contentStyle: { backgroundColor: colors.background },
        animation: "slide_from_right",
      }}
    >
      <Stack.Screen name="Home" component={HomeScreen} />
      <Stack.Screen name="DoctorDetails" component={DoctorDetailsScreen} />
      <Stack.Screen name="Appointment" component={AppointmentScreen} />
    </Stack.Navigator>
  );
}

export default function AppNavigator() {
  return (
    <Tab.Navigator
      screenOptions={({ route }) => ({
        headerShown: false,
        tabBarActiveTintColor: colors.primary,
        tabBarInactiveTintColor: colors.muted,
        tabBarStyle: {
          height: 70,
          paddingTop: 8,
          paddingBottom: 8,
          backgroundColor: colors.surface,
          borderTopColor: colors.border,
          elevation: 10,
        },
        tabBarLabelStyle: {
          fontSize: 11,
          fontWeight: "700",
        },
        tabBarIcon: ({ color, size }) => {
          const iconName = route.name === "HomeTab"
            ? "home-outline"
            : "chatbubble-ellipses-outline";
          return <Ionicons name={iconName} size={size + 1} color={color} />;
        },
      })}
    >
      <Tab.Screen
        name="HomeTab"
        component={HomeStackNavigator}
        options={{ title: "Home", tabBarLabel: "Home" }}
      />
      <Tab.Screen
        name="Assistant"
        component={AIChatScreen}
        options={{ title: "AI Assistant", tabBarLabel: "AI Assistant" }}
      />
    </Tab.Navigator>
  );
}

Gemini service

Keeps the network request outside the screen component. It first tries the offline FAQ answer when no API key exists; otherwise it sends the question and recent chat history to the Gemini generateContent REST endpoint.

Key concepts to understand
  • Separating UI from service logic
  • Reading EXPO_PUBLIC_ environment variables
  • fetch() and async/await
  • HTTP headers and JSON request body
  • Handling non-success HTTP responses
  • Client-side EXPO_PUBLIC_ keys are visible in the app bundle; use only a restricted demo key
src/services/gemini.js
import { hospitalInfo, getOfflineAnswer } from "../data/hospitalInfo";

const API_KEY = (process.env.EXPO_PUBLIC_GEMINI_API_KEY || "").trim();
const MODEL = (process.env.EXPO_PUBLIC_GEMINI_MODEL || "gemini-3.5-flash-lite").trim();

export const isGeminiConfigured = Boolean(API_KEY.trim());

export async function getGeminiAnswer(question, previousMessages = []) {
  // FAQs remain usable even before a student adds an API key.
  if (!isGeminiConfigured) {
    const offlineAnswer = getOfflineAnswer(question);
    if (offlineAnswer) return offlineAnswer;

    return "Gemini is not connected yet. Add your Google AI Studio key to the .env file to enable live AI replies. You can still try the FAQ questions above in demo mode.";
  }

  const history = previousMessages
    .filter((message) => message.role === "user" || message.role === "assistant")
    .slice(-8)
    .map((message) => ({
      role: message.role === "assistant" ? "model" : "user",
      parts: [{ text: message.text }],
    }));

  history.push({ role: "user", parts: [{ text: question }] });

  const systemPrompt = `You are the CityCare Teaching Hospital information assistant in a beginner React Native demo app.\n\nUse only the fictional hospital reference below to answer questions about the hospital. If the answer is not present, say that the guide does not contain that information. Do not invent facts, doctors, availability, prices, or policies. Keep answers friendly and concise.\n\nYou are not a doctor. Do not diagnose, recommend medicines, suggest treatment, or interpret symptoms. For urgent or emergency symptoms, advise the person to contact local emergency services or seek urgent in-person care.\n\nClearly explain that appointment booking in this app is a classroom demonstration and is not submitted to a real hospital.\n\nREFERENCE GUIDE:\n${hospitalInfo}`;

  const response = await fetch(
    `https://generativelanguage.googleapis.com/v1beta/models/${MODEL}:generateContent`,
    {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "x-goog-api-key": API_KEY,
      },
      body: JSON.stringify({
        systemInstruction: {
          parts: [{ text: systemPrompt }],
        },
        contents: history,
        generationConfig: {
          maxOutputTokens: 400,
          temperature: 0.2,
        },
      }),
    }
  );

  const data = await response.json();

  if (!response.ok) {
    const message = data?.error?.message || `Gemini request failed (${response.status}).`;
    throw new Error(message);
  }

  const answer = data?.candidates?.[0]?.content?.parts
    ?.map((part) => part.text || "")
    .join("")
    .trim();

  if (!answer) {
    throw new Error("Gemini returned an empty response. Please try again.");
  }

  return answer;
}
